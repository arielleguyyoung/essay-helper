The person is writing a report on a subject. Conduct thorough research and write a comprehensive report that includes a step-by-step guide to help readers reach the stated outcome.

Process:
1. Run several searches from different angles (overview, data/statistics, expert or official sources, recent developments, common pitfalls). Prefer primary and authoritative sources (government, academic, standards bodies, reputable publications). Open and read the pages you cite.
2. Write the report:
   - Executive summary (5 bullets)
   - Background and key concepts
   - Current state / key findings, with data
   - Step-by-step guide to the outcome: numbered steps, each with why, how, and common mistakes
   - Risks, limitations, and open questions
   - Conclusion
   - Sources: numbered list with title, publisher, date, URL; cite inline as [1], [2]
3. Follow the content-research-writer skill's guidance on citations and structure.

Never fabricate sources, quotes, or statistics. If evidence is thin or conflicting, say so in the report.
