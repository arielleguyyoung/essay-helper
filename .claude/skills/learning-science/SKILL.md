# Learning Science for Study Materials

Everything you produce for a learner should make them *retrieve and use* knowledge, not just re-read it.

## Principles and how to apply them
| Principle | What it means | Apply it by |
|---|---|---|
| Active recall | Pulling information out of memory strengthens it more than re-reading | End every guide with questions; phrase headings as questions; hide answers below questions |
| Spaced repetition | Reviews spread over growing gaps beat cramming | Schedule reviews at roughly 1, 3, 7, 14, 30 days; tag cards with a review interval |
| Interleaving | Mixing problem types builds discrimination | Mix topics in quizzes and practice sets instead of blocking by topic |
| Elaboration | Asking "why/how" links new ideas to old ones | Add "why this works" and "connects to..." lines |
| Concrete examples | Abstract ideas stick when anchored to cases | Give at least one everyday example per concept |
| Dual coding | Words + visuals beat words alone | Describe a diagram, flowchart, table, or mind map where it helps |
| Worked examples then fading | Beginners learn from full solutions, then partial ones | Show one fully solved problem, then one with steps missing |
| Feynman technique | If you can't explain it simply, you don't understand it | Offer a plain-language version and an exam-language version |
| Desirable difficulty | Effortful retrieval helps, as long as it is achievable | Mix easy, medium, and hard items; label them |
| Error correction | Feedback on mistakes is where learning happens | Always explain why wrong answers are wrong |

## Quality rules
- One idea per flashcard or question. No "list everything about X" cards.
- Match the learner's level; define jargon on first use.
- Accuracy over coverage: never invent facts, formulas, dates, or citations. If the source notes look wrong or incomplete, say so instead of papering over it.
- Prefer the learner's own material (notes, slides, syllabus) as the source of truth; flag where you added outside knowledge.
- Keep formatting scannable: headings, short bullets, tables for comparisons.
