Arielle's agent map

You talk to one agent, the orchestrator. It picks the right specialist for you. Agents are grouped below by when you'll need them in the year. Each card has a phrase to copy and type; put in your own topic, module or notes.

Start here

claude --agent orchestrator

Run this inside the essay-helper folder, then just ask in plain English. Paste notes or give a file path (for example notes/week3.md) so the agents work from your module material. To pick one agent yourself, say "use the flashcard-generator agent on ...".

After a lecture, before a seminar, or when a reading lost you.

text-summarizer

pareto-learning-coach

Before you submit anything

Check your module and department guidance on using AI in assessed work, and follow the university's academic integrity rules. Use the agents to understand, plan, practise and get feedback. Where the essay planner marks [ADD: ...], put in your own evidence and analysis.
